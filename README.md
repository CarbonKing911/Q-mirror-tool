# Q Mirror Date Tool

A single-file browser tool that turns any Q post date into direct, searchable links to historical news archives.

## What it does

Enter a date. The tool produces a 10-day window and gives you ready-to-click links to multiple public archives so you can examine the original reporting yourself. Results you mark are saved in your browser and shown in a running Coincidences table.

## How to use

1. Open `q-mirror-tool.html` in any browser.
2. Enter a date and click Calculate.
3. Follow the archive links and review the sources.
4. Mark the window Yes or No. The table updates automatically.

## Files

- `q-mirror-tool.html` — the complete tool (findings, calculator, and Coincidences table).

No installation or external dependencies required.
